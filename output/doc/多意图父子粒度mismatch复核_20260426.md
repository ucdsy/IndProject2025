## 标注建议

建议不要直接覆盖当前冻结数据集，而是在新的多意图评测版本中增加层级等价字段，例如：

```json
{
  "gold_intent_fqdns": ["hotel.travel.cn", "weather.cn"],
  "acceptable_fqdn_sets": [
    ["hotel.travel.cn", "weather.cn"],
    ["beijing.hotel.travel.cn", "weather.cn"]
  ],
  "hierarchy_equivalence": true
}
```

评估时同时报告：

- strict exact：完全匹配原 gold。
- hierarchy-relaxed exact：父子/回退链路等价匹配。
- set-F1：集合级部分正确。
- nDCG@K 或 mAP@K：候选排序质量。

这样可以区分“模型选错”和“模型选得更细但仍可执行”。
