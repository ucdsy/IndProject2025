# 专利 PDF 附图版说明

本目录为按专利说明书附图表达方式重绘的黑白块图版。

文件清单：
- 图1_系统总体结构示意图.pdf / png
- 图2_两层地址关系示意图.pdf / png
- 图3_协同决策结构示意图.pdf / png
- 图4_实例过滤与排序过程示意图.pdf / png
- 图5_决策轨迹组织示意图.pdf / png

本版重绘原则：
- 使用黑白块图和直线箭头，不使用展示型配色
- 一图只表达一个层次，避免把流程、架构、评分类细节混在同一张图里
- 将细粒度实现细节收进模块文字，不拆成过多独立节点
- 优先使用水平或垂直分层布局，减少交叉连线
